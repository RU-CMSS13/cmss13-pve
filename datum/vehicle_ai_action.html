/datum/vehicle_ai_action

Something the vehicle AI does, weighed every tick like /datum/ai_action of human AI.

SSvehicle_ai keeps one instance of each type to call get_weight() and get_conflicts() on, the brain makes its own instance for each action it starts.

Vars

brainThe brain doing this action, null on the singletons
weightThe weight this action started with. A heavier action that conflicts with it replaces it
