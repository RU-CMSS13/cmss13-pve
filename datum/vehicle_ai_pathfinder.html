/datum/vehicle_ai_pathfinder

A* search for the vehicle's center, spread over several ticks. A center turf can be used if the whole vehicle fits around it.

Vars

brainThe brain that receives the path
came_fromAssoc list of turf : the turf before it on the best path
center_costsAssoc list of center turf : path cost of the vehicle standing there, -1 if it can't
clear_onlyIf TRUE, the path may not go through anything the vehicle would have to crush. If there is no such path, a search that may is started
clear_only_max_nodesTotal tiles a clear_only search may look at, it gives up sooner since another search follows
closedAssoc list of turfs that are done
expandedTiles looked at so far
g_scoresAssoc list of turf : cost of the best path to it
goal_radiusThe search ends on any turf this close to the goal
heap_turfsBinary min-heap of open turfs, ordered by the matching heap_scores
max_nodesTotal tiles the search may look at before giving up
turf_costsAssoc list of turf : path cost of that one turf, -1 if the vehicle can't drive on it
turn_penaltyPath cost added each time the path turns, since the vehicle has to stop and rotate

Procs

searchLooks at up to budget tiles, then sends the path to the brain once it is done
